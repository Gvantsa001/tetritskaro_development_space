# თეთრიწყარო — განვითარების სივრცე

Django-ზე აგებული საწყისი ვერსია: მთავარი გვერდი, სიახლეები, ღონისძიებები, შესაძლებლობები, პროექტები და ადმინისტრატორის პანელი.

## გაშვება (Windows)

1. Python 3.11 ან უფრო ახალი ვერსიის დაყენება.
2. პროექტის საქაღალდეში ტერმინალის გახსნა.
3. ვირტუალური გარემოს შექმნა და გააქტიურება:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

4. დამოკიდებულებების დაყენება:

```powershell
pip install -r requirements.txt
```

5. მონაცემთა ბაზის მომზადება და ადმინისტრატორის შექმნა:

```powershell
python manage.py migrate
python manage.py createsuperuser
```

6. სერვერის გაშვება:

```powershell
python manage.py runserver
```

საიტი: http://127.0.0.1:8000/
ადმინისტრატორი: http://127.0.0.1:8000/admin/

## მნიშვნელოვანი შენიშვნები

- საწყისი ვერსია იყენებს SQLite-ს, ამიტომ ცალკე მონაცემთა ბაზის დაყენება არ არის საჭირო.
- ადმინისტრატორში დაამატეთ სიახლეები და ღონისძიებები; გამოქვეყნების ველი მონიშნეთ.
- `SECRET_KEY`, `DEBUG` და `ALLOWED_HOSTS` შეცვალეთ რეალურ განთავსებამდე.
- `sheuertdi/` ფორმა ამ ვერსიაში მხოლოდ შეტყობინებას აჩვენებს; შეტყობინებების შენახვა და ელფოსტით გაგზავნა შემდეგ ეტაპზე უნდა დაემატოს.
- ფოტოების ველები ამ ვერსიაში URL-ით მუშაობს.
